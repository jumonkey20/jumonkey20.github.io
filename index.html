# Overview

This project investigates the genetic divergence of key resistance and outer-membrane porin genes (such as oprD) across different strains of Pseudomonas aeruginosa[cite: 1]. By leveraging programmatic sequence alignment tools in Python, this workflow automates the detection of Single Nucleotide Polymorphisms (SNPs) and calculates percentage identity matrices between reference and clinical isolates[cite: 1].

# Objectives

  • Automate Data Retrieval: Curate and manage FASTA-formatted nucleotide sequences from NCBI GenBank[cite: 1].
  • Sequence Alignment: Implement global pairwise sequence alignments using Biopython[cite: 1].
  • Variant Analysis: Quantify sequence identity scores and map divergence to understand potential mechanisms of antimicrobial resistance[cite: 1].

# Methodology & Tech Stack

  • Data Collection: Retrieved full-length coding sequences for target resistance-associated loci from *Pseudomonas aeruginosa* PAO1 (reference) and select variant strains via NCBI[cite: 1].
  • Computational Pipeline: Developed a Python-based analysis script utilizing the Biopython library (`Bio.Align`)[cite: 1].
  • Scoring Matrix: Executed global Needleman-Wunsch alignments with optimized gap penalties to evaluate sequence conservation and highlight structural mutation hotspots[cite: 1].
  • Stack: Python 3.x, Biopython, Pandas, Matplotlib, NCBI Nucleotide / GenBank[cite: 1].

# Step-by-Step Replication Guide

Step 1: Install Dependencies

pip install biopython pandas

Step 2: Create Data File

Place your multi-FASTA reference (`NP_249649.1_Reference_PAO1`) and variant files inside a `data/` folder[cite: 1].

Step 3: Execute Pipeline Script

python analyze_resistance.py

# About This Project

Authored by Ali Al-Jumaili, an undergraduate Biomedical Science student at the University of Surrey[cite: 2]. This repository showcases independent exploration into bioinformatics and structural biology, specifically focusing on molecular docking simulations[cite: 2].

Rather than relying purely on complex terminal-based scripting, this project demonstrates a streamlined, user-friendly virtual screening workflow using PyRx (AutoDock Vina GUI)[cite: 2]. Ligand-protein binding interactions—such as docking PRIMA-1 against target receptors like 1TUP—are analyzed to evaluate binding affinities and structural conformations efficiently[cite: 2].

# Repository Structure

p53-prima1-molecular-docking/
├── data/
│   ├── ligands/          # Input ligand files (SDF / PDBQT)
│   ├── pdb_structures/   # Target receptor protein files (1TUP)
│   └── processed/        # Generated docking output poses and score tables
├── results/              # Organized analysis output files
└── scripts/              # Custom automation or analysis scripts

# Virtual Screening Workflow (PyRx GUI)

  • Load Molecules: Open PyRx, navigate to the AutoDock tab, and add your ligand and macromolecule (`.pdbqt` files, e.g., 1TUP)[cite: 2].
  • Select Molecules: Check boxes in the Navigator tree and proceed to the Vina Wizard search space setup[cite: 2].
  • Define Search Space: Adjust grid box dimensions and center coordinates in the 3D viewer to cover the active binding site[cite: 2].
  • Analyze & Export: Review Binding Affinity ($\text{kcal/mol}$) values and export docked conformations into your `data/processed/` directory[cite: 2].
