Pseudomonas oprD Gene & Resistance Profiling

Project Breakdown & Video Walkthrough

# Biological Context & Objectives

Investigates genetic divergence and antimicrobial resistance markers in Pseudomonas aeruginosa by targeting the oprD gene encoding the OprD outer-membrane porin channel.

# Pipeline Methodology

  • Data Parsing: Ingests multi-FASTA files containing reference strain PAO1 (Accession: NP_249649.1) and variant clinical isolates using Biopython's SeqIO.
  • Global Alignment: Implements the Needleman-Wunsch algorithm via Biopython's PairwiseAligner() with custom gap scores (open: -10, extend: -0.5).
  • Quantification & Export: Programmatically calculates match counts, total lengths, and percentage identities into a Pandas DataFrame exported as alignment_results.csv.

p53 & PRIMA-1 Molecular Docking Pipeline

Project Breakdown & Video Walkthrough

# Biological Context & Objectives

A structural bioinformatics workflow investigating ligand-protein binding interactions to evaluate the pharmacological restoration of mutant p53 proteins using small-molecule PRIMA-1.

# Workflow Methodology

  • Structure Preparation: Imports target macromolecule PDB structures (such as 1TUP) and prepares ligand coordinate files into PDBQT format.
  • Grid Box Optimization: Defines active binding site coordinates and bounding boxes to bound conformational search spaces.
  • Execution & Scoring: Executes AutoDock Vina calculations via PyRx to compute binding affinities ($\text{kcal/mol}$) and rank docking conformations.
